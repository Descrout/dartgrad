# dartgrad documentation

These guides cover the main concepts and public APIs provided by `dartgrad`.

- [Getting started](getting-started.md): install the package and evaluate a
  first expression.
- [Automatic differentiation](automatic-differentiation.md): create a
  computation graph and calculate gradients.
- [Neural networks](neural-networks.md): construct and train an `MLP`.

For a complete training program, see
[`example/dartgrad_example.dart`](../example/dartgrad_example.dart). API
reference documentation is generated from the public library exported by
`package:dartgrad/dartgrad.dart`.
